# 2. Syntax & Basic Types

## Variable Declarations

```go
// 1. Short declaration (type inferred, functions only)
name := "Alice"
age := 25

// 2. Explicit var declaration
var score int = 100
var city string // defaults to zero value ""

// 3. Grouped declaration
var (
	host = "localhost"
	port = 8080
	ssl  = true
)
```

## Basic Data Types

| Category | Types | Examples |
| :--- | :--- | :--- |
| **Booleans** | `bool` | `true`, `false` |
| **Integers** | `int`, `int8`, `int16`, `int32`, `int64` | `-42`, `100` |
| **Unsigned Integers** | `uint`, `uint8` (`byte`), `uint16`, `uint32`, `uint64` | `0`, `255` |
| **Floats** | `float32`, `float64` | `3.14`, `-0.001` |
| **Characters** | `byte` (alias for `uint8`), `rune` (alias for `int32`, represents a Unicode code point) | `'A'`, `'世'` |
| **Strings** | `string` (immutable UTF-8 sequence) | `"Hello \n"`, `` `raw string` `` |

---

## Zero Values
Variables declared without an explicit initial value are given their **zero value**:

* Numeric types (`int`, `float`): `0`
* Booleans: `false`
* Strings: `""` (empty string)
* Pointers, slices, maps, channels, functions, interfaces: `nil`

## Constants & `iota`

```go
// Simple constants
const Pi = 3.14159
const AppName = "MyApp"

// Enums using iota (auto-increments starting from 0)
const (
	Pending   = iota // 0
	Active           // 1
	Completed        // 2
	Failed           // 3
)
```

## Type Conversion
Go requires **explicit type casting**; there is no implicit coercion:

```go
var a int = 42
var b float64 = float64(a)
var c uint = uint(a)
```
