# 8. Concurrency Basics

## Goroutines

A goroutine is a lightweight, independently executing function managed by the Go runtime (much lighter than an OS thread).

```go
func printMessage(msg string) {
	fmt.Println(msg)
}

func main() {
	// Start concurrent execution using the 'go' keyword
	go printMessage("Running concurrently in background")

	// Wait or synchronize (otherwise main may exit before goroutine runs)
	time.Sleep(100 * time.Millisecond)
}
```

---

## Channels

Channels are typed conduits through which goroutines communicate and synchronize.

```go
// Create an unbuffered channel
messages := make(chan string)

// Send data into channel in goroutine
go func() {
	messages <- "ping" // Send
}()

// Receive from channel (blocks until data is received)
msg := <-messages // Receive
fmt.Println(msg)
```

### Buffered Channels
Buffered channels accept a limited number of values without a blocking receiver.
```go
ch := make(chan int, 2)
ch <- 1
ch <- 2 // Does not block because buffer size is 2
```

---

## `sync.WaitGroup`

The idiomatic way to wait for multiple concurrent goroutines to complete.

```go
var wg sync.WaitGroup

for i := 1; i <= 3; i++ {
	wg.Add(1) // Increment counter

	go func(id int) {
		defer wg.Done() // Decrement counter when finished
		fmt.Printf("Worker %d finished\n", id)
	}(i)
}

wg.Wait() // Blocks until counter reaches 0
fmt.Println("All workers done")
```

---

## The `select` Statement

Lets a goroutine wait on multiple channel operations simultaneously.

```go
select {
case msg1 := <-ch1:
	fmt.Println("Received from ch1:", msg1)
case msg2 := <-ch2:
	fmt.Println("Received from ch2:", msg2)
case <-time.After(1 * time.Second):
	fmt.Println("Timeout")
}
```
