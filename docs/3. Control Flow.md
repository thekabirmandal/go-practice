# 3. Control Flow

## If / Else Statement

Go `if` statements do not need parentheses around conditions, but `{}` are required.

```go
// Standard if / else
if score >= 90 {
	fmt.Println("Grade: A")
} else if score >= 80 {
	fmt.Println("Grade: B")
} else {
	fmt.Println("Grade: C")
}

// If with inline initialization statement (scope of 'val' is limited to if/else)
if val := calculate(); val > 10 {
	fmt.Println("Above threshold:", val)
}
```

## Switch Statement

* Cases do **not** fall through by default (no `break` needed).
* Multiple conditions can be comma-separated.

```go
// Expression switch
switch day := "Monday"; day {
case "Saturday", "Sunday":
	fmt.Println("Weekend")
case "Monday":
	fmt.Println("Start of work week")
default:
	fmt.Println("Midweek")
}

// Condition-less switch (cleaner alternative to long if-else chains)
switch {
case score >= 90:
	fmt.Println("Excellent")
case score >= 75:
	fmt.Println("Good")
default:
	fmt.Println("Needs Improvement")
}
```

## Loops (Only `for`)

Go has only one looping keyword: `for`.

```go
// 1. Standard C-style loop
for i := 0; i < 5; i++ {
	fmt.Println(i)
}

// 2. While-style loop (condition only)
count := 1
for count < 10 {
	count *= 2
}

// 3. Infinite loop (exit with break)
for {
	if shouldStop() {
		break
	}
}

// 4. For with range (over slices, maps, strings)
numbers := []int{10, 20, 30}
for index, value := range numbers {
	fmt.Printf("Index: %d, Value: %d\n", index, value)
}

// Ignore index with blank identifier (_)
for _, value := range numbers {
	fmt.Println("Value:", value)
}
```
