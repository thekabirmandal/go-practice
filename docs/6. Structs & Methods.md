# 6. Structs & Methods

## Structs (Custom Types)

Go does not have classes. Structs are typed collections of fields.

```go
type User struct {
	ID       int
	Username string
	Email    string
	IsAdmin  bool
}

// Creating struct instances
u1 := User{
	ID:       1,
	Username: "alice",
	Email:    "alice@example.com",
	IsAdmin:  false,
}

// Struct pointer
u2 := &User{ID: 2, Username: "bob"}
u2.Email = "bob@example.com" // Go allows dot notation directly on pointers
```

---

## Methods

Methods are functions with a **receiver** parameter between `func` and the method name.

### Value Receiver vs. Pointer Receiver

```go
// Value receiver: operates on a COPY of the struct (cannot mutate original)
func (u User) Greeting() string {
	return "Hello, " + u.Username
}

// Pointer receiver: operates on the ORIGINAL struct (can mutate fields & avoids copying large structs)
func (u *User) SetEmail(newEmail string) {
	u.Email = newEmail
}
```

## Struct Embedding (Composition)

Go uses composition instead of classical inheritance.

```go
type Person struct {
	Name string
	Age  int
}

// Admin embeds Person (fields and methods of Person are promoted to Admin)
type Admin struct {
	Person
	AccessLevel int
}

// Usage:
admin := Admin{
	Person:      Person{Name: "Carol", Age: 35},
	AccessLevel: 1,
}

fmt.Println(admin.Name) // Directly access promoted field
```
