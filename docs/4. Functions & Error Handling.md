# 4. Functions & Error Handling

## Function Basics

```go
// Standard function with typed parameters and return value
func add(a int, b int) int {
	return a + b
}

// Multiple parameters of the same type
func multiply(a, b int) int {
	return a * b
}

// Multiple return values (standard Go idiom: result + error)
func divide(a, b float64) (float64, error) {
	if b == 0 {
		return 0, errors.New("cannot divide by zero")
	}
	return a / b, nil
}
```

---

## Variadic Functions
Functions that accept any number of trailing arguments using `...Type`.

```go
func sum(numbers ...int) int {
	total := 0
	for _, n := range numbers {
		total += n
	}
	return total
}

// Usage:
// sum(1, 2, 3)
// sum(slice...)
```

---

## The `defer` Statement
Defers execution of a function until the surrounding function returns.
Commonly used for cleanup (closing files, unlocking mutexes, closing network connections).

```go
func processFile(filename string) error {
	file, err := os.Open(filename)
	if err != nil {
		return err
	}
	defer file.Close() // Will execute automatically before processFile exits

	// Read and process file...
	return nil
}
```
*Note: Multiple defers execute in **LIFO (Last In, First Out)** order.*

## Idiomatic Error Handling
Go handles errors as normal return values, rather than throwing exceptions.

```go
result, err := divide(10, 2)
if err != nil {
	fmt.Printf("Error: %v\n", err)
	return
}
fmt.Println("Result:", result)
```
