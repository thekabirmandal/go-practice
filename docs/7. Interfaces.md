# 7. Interfaces

## Implicit Interfaces

An interface defines a set of method signatures. In Go, types implement interfaces **implicitly** by implementing all required methods — there is no `implements` keyword.

```go
// 1. Define an interface
type Greeter interface {
	Greet() string
}

// 2. Concrete types
type Human struct {
	Name string
}

func (h Human) Greet() string {
	return "Hello, I am " + h.Name
}

type Robot struct{}

func (r Robot) Greet() string {
	return "Beep boop!"
}

// 3. Function accepting the interface
func SayHello(g Greeter) {
	fmt.Println(g.Greet())
}

// Usage:
SayHello(Human{Name: "Sam"})
SayHello(Robot{})
```

---

## Empty Interface (`any` / `interface{}`)

The empty interface specifies zero methods, so **every type implements it**. Used for dynamic/untyped data.

```go
func printAnything(val any) { // 'any' is an alias for interface{}
	fmt.Println("Value:", val)
}
```

---

## Type Assertions & Type Switches

Used to inspect and extract the underlying concrete value from an interface.

```go
var i any = "hello"

// 1. Type Assertion ("comma ok" pattern)
str, ok := i.(string)
if ok {
	fmt.Println("String:", str)
}

// 2. Type Switch
switch v := i.(type) {
case int:
	fmt.Println("Integer:", v)
case string:
	fmt.Println("String:", v)
case bool:
	fmt.Println("Boolean:", v)
default:
	fmt.Printf("Unknown type: %T\n", v)
}
```
