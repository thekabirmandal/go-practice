# 1. Introduction & Setup

## What is Go?
* Statically typed, compiled language developed by Google.
* Key design goals: **simplicity**, **fast compilation**, and **built-in concurrency**.
* Memory managed with automatic garbage collection.

---

## Toolchain & Essential Commands

```bash
# Initialize a new module
go mod init my-project

# Run a Go file directly without producing a persistent binary
go run main.go

# Compile into a standalone executable binary
go build -o app.exe main.go

# Auto-format code to idiomatic Go style
go fmt ./...

# Add missing dependencies and remove unused ones
go mod tidy

# Run tests (*_test.go)
go test ./...
```

---

## Basic Program Structure

```go
// 1. Package declaration (package main produces an executable binary)
package main

// 2. Imports from standard library or dependencies
import (
	"fmt"
)

// 3. Main entrypoint function (no parameters, no return values)
func main() {
	fmt.Println("Hello, Go!")
}
```

---

## Exported vs. Unexported Identifiers
Visibility is determined solely by the capitalization of the first letter:
* **Exported (Public)**: Starts with a Capital letter (e.g., `fmt.Println`, `http.StatusOK`, `User`). Accessible across packages.
* **Unexported (Private)**: Starts with a lowercase letter (e.g., `calculateTotal`, `config`). Accessible only within the same package.
