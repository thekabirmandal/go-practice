# 5. Collections & Pointers

## Arrays vs. Slices

### Arrays
Fixed-size sequence of elements of the same type.
```go
var arr [3]int = [3]int{1, 2, 3}
arr[0] = 10
// len(arr) is fixed at 3
```

### Slices
Dynamically-sized, flexible view into an array.
```go
// 1. Literal declaration
nums := []int{10, 20, 30}

// 2. Using make(type, length, capacity)
items := make([]string, 0, 5)

// 3. Append elements (grows dynamically)
nums = append(nums, 40, 50)

// 4. Slicing syntax: slice[start:end] (end index is exclusive)
subSlice := nums[1:3] // [20, 30]
```

## Maps (Key-Value Pairs)

Unordered collection of key-value pairs (hash table).

```go
// 1. Create a map
userAges := make(map[string]int)
userAges["Alice"] = 28
userAges["Bob"] = 32

// Map literal
colors := map[string]string{
	"red":   "#FF0000",
	"green": "#00FF00",
}

// 2. Check if a key exists ("comma ok" idiom)
age, exists := userAges["Charlie"]
if !exists {
	fmt.Println("User not found")
}

// 3. Delete a key
delete(userAges, "Bob")
```

## Pointers

A pointer holds the memory address of a variable.
* `&` gets the memory address of a variable.
* `*` dereferences the pointer (reads or modifies the value at that address).
* *Note: Go has no pointer arithmetic (like `p++`).*

```go
x := 10
ptr := &x // ptr is of type *int

fmt.Println("Address:", ptr)
fmt.Println("Value:", *ptr) // 10

*ptr = 25 // Modifies the value of x
fmt.Println("New x value:", x) // 25
```

### Passing by Value vs. Pointer
```go
// Passes copy of value (original is unchanged)
func incrementValue(n int) {
	n++
}

// Passes pointer (modifies the caller's variable)
func incrementPointer(n *int) {
	*n++
}
```
